# 명도재 아트웹 스튜디오 — 관리자 데모 v1.0

## 포함 파일
- `index.html`: 관리자 대시보드, 프로젝트 등록/관리, 홈페이지 미리보기
- `style.css`: 반응형 한국어 관리자 디자인
- `app.js`: 프로젝트 등록·수정·삭제, 상태 필터, JSON 내보내기, 브라우저 로컬 저장

## 설치
1. GitHub 저장소 `mmwwoo-lab/myeongdo-artweb`의 `main` 브랜치에 위 3개 파일을 `admin/` 경로로 업로드합니다.
2. GitHub Pages가 `main`/`(root)` 기준으로 활성화되면 `/myeongdo-artweb/admin/` 에서 표시됩니다.
3. 기존 `admin/` 경로에 파일이 있으면 덮어쓰기 전에 백업·비교해야 합니다.

## 중요한 보안 제한
이것은 공개 데모입니다. 로그인·서버 인증·고객별 권한·실제 업로드·사이트 배포 기능이 없습니다.
프로젝트 데이터는 해당 브라우저의 localStorage에만 저장됩니다. 브라우저 데이터를 지우면 사라질 수 있습니다.
**실명 고객정보, 연락처, 계좌, 계약정보, 비공개 작품이나 API 키를 절대 입력하지 마세요.**
고객 영업용 관리자 기능에는 서버 인증 및 접근권한 보호가 필요합니다.

## 정식 서비스 다음 단계
Supabase Auth·DB·Storage 또는 동등한 백엔드를 붙이고, 서버 측 접근권한, 업로드 보안, 실제 템플릿 엔진, 발행·배포 시스템을 구축합니다.
