# 명도재 아트웹 관리자 v7.0

## 주요 기능
- 만화로 보는 뉴스 / 문학관 / 시집 출간 기념관 / 시가 머무는 집 / 한국화 초대전 유형별 맞춤 편집기
- 글 중심 유형: 그림·작품 3장 + 본문 글쓰기 중심
- 전시 유형: 작품 6장 + 작품별 설명 + 전체 작품 평론
- 작품 평론 자동 생성(약 200자)
- 시 원문 기반 9:16 수채화풍 SVG 시화 자동 생성
- JPG/HWP/TXT 원고 첨부, 작품 이미지 업로드, 저장/재편집, HTML 시안 미리보기·다운로드

## 주의
- 현재 버전은 GitHub Pages 같은 정적 환경에서도 동작하는 브라우저 내 시연용 앱입니다.
- 저장 데이터는 현재 브라우저의 localStorage에 저장됩니다.
- 실제 고객 개인정보, 비공개 원고, 고용량 이미지는 사용하지 마세요.
- 시화 자동 생성은 외부 AI 이미지 생성이 아니라 브라우저 내 규칙 기반 SVG 생성입니다.

## v7.1 수정 사항
- 기존 v6 프로젝트 목록에서 신규 버전으로 일회성 가져오기 (신규 저장 키가 비어있을 때)
- 이미지를 등록하지 않은 상태에서 평론 작성 버튼 사용 시 안내
- SVG 시화 텍스트 이스케이프 점검
- 실제 이미지 인식 AI가 아니라 작품 설명을 사용한 약 200자 평론 초안임을 명확히 표기
## v7.8 시화 개선
- 시어 기반 삽화형 SVG 시화 장면 구성과 가로형/세로형 자동 선택
- 기존 프로젝트 관리 및 작품별 30초 음악 기능 유지
- 실제 AI 이미지 생성 API는 연결되지 않은 규칙 기반 삽화입니다.
