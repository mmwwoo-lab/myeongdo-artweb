# 명도재 아트웹 관리자 v8.0

## 전체 검토 요약
이 버전은 명도재 아트웹의 핵심 정체성을 더 분명하게 반영하도록 보완했습니다.

### 1) 미술 작가 소개형 홈페이지
- 작가 소개 / 작가 약력 / 문의 정보 입력
- 작품 3장 또는 6장 업로드
- 작품 설명 입력
- 작품 이미지 색감과 작품 설명을 함께 참고해 **30초 이내 서양 클래식풍 창작 기악곡** 생성
- 생성된 홈페이지에서 **음악 생성·듣기 버튼 + 오디오 조절바** 제공

### 2) 시 문학 사이트
- 시 원문 기반 자동 시화 생성
- 세로형 / 가로형 비율 자동 선택
- 수채화풍 삽화 배경 + 시 글씨 + 제목 + 낙관 구성
- SVG로 다운로드 가능

### 3) 만화로 보는 뉴스
- 기사 입력 시 **3열 × 4행(12컷)** 또는 **2열 × 4행(8컷)** 뉴스 만화 시안 생성
- 컷 설명, 말풍선 텍스트, 핵심 기사 전달 구성
- 정적 웹앱 환경이므로 실사형 AI 이미지 생성 대신 **구성형 뉴스 만화 시안**으로 구현

## 한계와 설명
- 본 버전은 정적 웹앱이므로 실제 AI 화가/AI 작곡 API를 호출하지 않습니다.
- 작품 음악은 **이미지 평균 색감 + 작품 설명 키워드**를 기반으로 생성하는 브라우저 내 창작 기악곡입니다.
- 뉴스 만화 역시 기사 내용을 바탕으로 컷 구성과 말풍선을 자동 생성하는 시안형 기능입니다.
