# 명도재 AI 홈페이지 제작회사 운영 규정 v2 — 10개 부서

## 감사 결과
현재 업무실은 브라우저 저장 기반 수동 프로젝트/부서 관리 시스템이다. 자동 뉴스 검색·문장 생성·그림 생성·음악 생성·Python 서버 실행·자동 배포 기능은 없다. 따라서 부서가 독립적으로 업무를 수행한다고 표시하지 않는다.

## 조직 및 책임
1. 경영·업무총괄실 — 고객 요청, 업무지시, 담당부서 배정, 품질 기준·최종 승인.
2. 자료조사·기획부 — 공식기관/언론사 검색, 4~8건 후보 목록, 날짜·지역·출처·링크 교차검증, 기획서.
3. 콘텐츠·웹기획부 — 독립 기사 재작성, 제목·리드·본문·안내문, 웹 구조, 원문 출처 링크.
4. AI 미술제작부 — 본문에 근거한 실제 삽화/8컷 뉴스 만화 콘티·제작, 이미지 사용권 기록.
5. AI 음악제작부 — 필요 시 주제가·BGM·낭송용 음악 계획, 외부 음원 생성 도구 연결/제작.
6. 문학창작부 — 기사 주제와 연결한 시·가사 제작(선택), 원저작권 확인.
7. 시화디자인부 — 승인된 시와 그림의 시화 디자인(선택), 9:16·16:9·인쇄 규격.
8. 문학평론·편집부 — 미술평론·문화칼럼·기사 사실 검증·교열·인용·저작권 심사.
9. 웹개발·품질관리부 — 기사/시화/만화/음악을 통합, 접근성·반응형·링크·배포 확인.
10. Python 프로그램 지원부 — Pillow/SVG 이미지 최적화, 컷/표지 레이아웃 합성, WAV 메타데이터/형식 점검, 반복 편집 자동화, 파일 검사.

## 편집국 제작 흐름
대표 지시 → 조사부가 후보·출처 제출 → 총괄 승인 → 콘텐츠부가 사실만 활용해 **독립적으로 재작성** → 미술부·음악부·문학부가 필요한 결과물 기획 → Python 지원부가 파일 규격 정리 → 평론·편집부가 인용, 초상권, 이미지 출처와 오탈자 심사 → 웹개발부가 링크와 반응형 테스트 → 대표 최종 확인 → 출판.

## 필수 검수
- 사건/일정/수치/기관 확인 근거 링크 기록, 출처 취재기사 장문 복제 금지
- 행사 표제와 날짜·장소를 적어도 공식 주최처 또는 복수의 자료로 확인
- 비평·칼럼과 사실 보도를 구분
- 실제 작품 사진을 가공 그림이라고 속이거나 임의 대체 금지
- 승인된 시와 이미지·음원에 대한 이용 허락 확인
- 이미지를 생성했다면 생성 엔진·규격, Python 처리 기록, 사용 여부를 명시
- 공개 사이트 링크가 실제 작동하는지 확인 후 배포 완료로 기록

## 도구
- 운영실: /admin/agency.html (브라우저 내부 저장/JSON 백업)
- Python 지원부: /tools/python-support/asset_pipeline.py (로컬 Python 환경에서 실행)
- 소식지 창간 시안: /culture-news/
- 웹 편집기: /admin/#create

## 실제 구현 범위
행정 UI는 업무 접수·배정·단계별 상태/보고서 관리만 제공한다. 검색 바로가기를 누르는 것과 실시간 검색·생성 자동화는 다른 기능이다. Python 프로그램은 GitHub Pages에서 자동 실행되지 않으며 PC/서버에서 수동 실행해야 한다.
