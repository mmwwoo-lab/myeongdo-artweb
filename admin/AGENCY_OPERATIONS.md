# 명도재 AI 홈페이지 제작회사 — 업무 운영 규정 v1
## 목적
한 건의 대표 업무지시를 부서별 산출물과 승인 기준으로 분해하여 홈페이지로 출판한다. 부서명은 역할이며 실제 직원이나 자율 AI 에이전트를 의미하지 않는다.

## 핵심 흐름
업무 접수 → 조사·기획 → 콘텐츠·웹구성 → 필요 시 병렬 창작(미술·음악·시·시화) → 평론·교정 → 웹개발·검수 → 대표 승인·배포.

## 부서별 책임·인수인계 기준
1. 경영·업무총괄실: 목표, 타깃 독자, 납기, 결과 형식, 승인 기준 결정. 기획 승인 및 최종 공개 결정.
2. 자료조사·기획부: 검색 출처(저자/매체/URL/발행일), 검증 여부, 미확인 사항, 저작권 제한, 제작 기획안.
3. 콘텐츠·웹기획부: 사이트맵, 페이지별 구조, 제목·본문·CTA, 출처 링크, 이미지 및 음악 요구사항. 기사 저작권을 침해하는 무단전재 금지.
4. AI 미술제작부: 그림 콘셉트, 크기/비율, 장면별 프롬프트, 실제 생성 또는 검증된 이미지 자료, 캡션. 생성 전/후 구별.
5. AI 음악제작부: 시/이미지 해석, 장르/편곡/보컬 요구사항, 음악 프롬프트와 음원 권리·링크. 실제 생성 엔진 연결 전에는 제작 완료로 표시하지 않음.
6. 문학창작부: 시와 가사 원고, 원작·2차 창작 여부, 저자 표기.
7. 시화디자인부: 최종 승인된 시 텍스트와 이미지, 한글 표기 교정, 9:16 / 16:9 결과물.
8. 문학평론·편집부: 비평, 문장 교정, 사실 관계, 출처, 이미지·음악 저작권, 대외 공개 전 점검.
9. 웹개발·품질관리부: 편집, 접근성·모바일·링크·응답성 검수, 실제 배포 URL 테스트, 인수인계·백업.

## 유형별 운영
- 뉴스 만화: 조사·기획 / 콘텐츠·웹 / 이미지 / 편집 / 개발 필수. 음악·시·시화 선택.
- 미술 전시: 조사·기획 / 콘텐츠·웹 / 이미지 / 음악 / 편집 / 개발.
- 문학·시화: 조사·기획 / 콘텐츠·웹 / 이미지 / 시 / 시화 / 평론 / 개발.
- 음악 홍보: 조사·기획 / 콘텐츠·웹 / 이미지 / 음악 / 시 / 편집 / 개발.
- 종합 홈페이지: 전체 부서.

## 업무보고서
각 부서의 상태: 대기 / 진행 중 / 검수 요청 / 완료. 결과물에는 산출물 링크, 작업 프롬프트, 출처, 이슈, 승인 내역을 기재한다.
최종 배포 전 대표는 콘텐츠 정확성, 권리, 링크, 모바일 호환성, 접근성, 공개 동의를 검토한다.

## 현재 구현 범위
admin/agency.html은 로컬 브라우저 저장 기반 수동 업무 운영실이다. 자동 인터넷 검색·외부 이미지 생성·음악 제작·AI 시평 작성·에이전트 간 자동 전달은 연결되지 않았다.
생성 엔진과 계정/서버/권한을 연결하기 전에는 AI 부서가 실제로 독립 실행된다고 표시하지 말 것.
