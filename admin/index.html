설정

작품 음악은 이미지 색감과 설명을 함께 참고해 30초 이내의 창작 서양 클래식풍 기악곡으로 구성합니다.

시화 자동 생성

시 내용을 분석하여 수채화풍 삽화 배경과 시 글씨를 결합한 시화를 생성합니다. 내용에 따라 세로형 또는 가로형을 자동 선택합니다.

아직 생성된 시화가 없습니다.

뉴스 만화 자동 구성

기사 내용을 요약해 3열 × 4행 또는 2열 × 4행 뉴스 만화 시안으로 구성합니다. 말풍선 텍스트와 컷 설명을 자동 배치합니다.

아직 생성된 뉴스 만화가 없습니다.

작품·이미지 등록

유형에 따라 3장 또는 6장의 이미지 업로드가 가능합니다. 큰 이미지는 자동 축소·압축됩니다.

파일 미선택 · TXT는 본문으로 불러오고, JPG는 미리보기, HWP는 첨부 보관용입니다.

입력 내용은 오른쪽 미리보기에 즉시 반영됩니다.

사용 안내

명도재 아트웹의 특징과 한계를 함께 확인하세요.

  • 미술 홈페이지: 작가 소개, 약력, 작품 소개, 작품별 음악 감상 조절바를 제공합니다.
  • 작품 음악: 작품 이미지의 평균 색감과 밝기, 작품 설명의 키워드를 바탕으로 30초 이내 서양 클래식풍 창작 기악곡을 만듭니다.
  • 시 문학 사이트: 시 원문을 바탕으로 세로형/가로형 삽화 시화를 SVG로 생성합니다.
  • 만화로 보는 뉴스: 기사 내용을 분석하여 3열 × 4행 또는 2열 × 4행 뉴스 만화 시안으로 자동 구성합니다.
  • 중요: 본 프로그램은 정적 웹앱 기반 시연용입니다. 실사형 AI 이미지·전문 작곡 AI·뉴스 사진 생성 API를 직접 연결한 것은 아닙니다.
