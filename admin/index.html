미술작품 전시 홈페이지 제작방

예술 작품은 전시장의 벽을 넘어 더 많은 사람과 만날 수 있습니다. 작가의 이야기와 작품 원본, 제작기록, 미술평론, 음악·영상 감상을 하나의 개인 홈페이지로 엮어 새로운 전시 공간을 만들어 보세요.

작가의 세계를 기록하고작품의 의미를 전달하며온라인에서 함께 감상합니다
왜 개인 전시관이 필요할까요?

전시 기간과 지역의 제약을 넘어 작품과 작가를 지속적으로 소개하고, 원작과 작가노트의 의미를 함께 기록할 수 있기 때문입니다.

어떤 작품을 소개할 수 있나요?

한국화·서양화·수채화·판화·조각·사진예술·공예 등 다양한 미술 분야의 작품을 이미지와 자료로 등록할 수 있습니다.

어떻게 관람객에게 전달되나요?

표지와 작가 약력, 작품별 사진·제목·제작연도·재료·크기·해설·미술평론, 음악·영상 링크가 전시 형식으로 구성됩니다.

USER GUIDE

미술작품 전시 홈페이지 사용 방법

작가와 전시 정보를 작성한 후 작품 추가 버튼을 눌러 작품을 등록합니다. 각 작품마다 원본 이미지, 제목, 연도, 재료·크기, 작품 해설과 음악·영상 주소를 따로 저장할 수 있습니다.

작품 영상 제작: 작품 등록 후 「영상 제작용 JSON 내려받기」로 자료를 백업하고 Python 영상제작 프로그램에서 MP4를 만듭니다. 출력된 video-manifest.json을 「Python 영상 결과 등록」에서 가져오면 작품별 제작 상태를 확인할 수 있습니다. MP4 파일을 GitHub 또는 영상 저장 서비스에 업로드한 후 링크를 연결해야 전시 홈페이지에서 동영상이 재생됩니다.

미리보기 버튼으로 전시관의 모습을 확인하고, HTML 파일을 내려받아 배포용 서버나 웹 호스팅에 게시할 수 있습니다. 저장한 작업은 이 브라우저에서 다시 편집할 수 있습니다.

주의: 이 제작기는 서버 연동 없이 동작하는 정적 페이지입니다. 입력 내용과 작품 이미지는 사용하는 브라우저에만 저장됩니다. 다른 기기에서 공유·공동 편집하려면 JSON 백업 파일을 전달하거나 별도의 서버가 필요합니다. HTML 다운로드가 공개 배포를 의미하지는 않습니다.

이전에 저장한 미술 전시 데이터가 있으면 최초 실행 시 구버전에서 복사하여 표시합니다. 다른 종류의 프로젝트는 기존 저장소에서 제거하지 않고, 새 제작기에서 표시하지 않습니다.
