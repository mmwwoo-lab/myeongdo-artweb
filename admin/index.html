USER GUIDE

미술작품 전시 홈페이지 사용 방법

작가와 전시 정보를 작성한 후 작품 추가 버튼을 눌러 작품을 등록합니다. 각 작품마다 원본 이미지, 제목, 연도, 재료·크기, 작품 해설과 음악·영상 주소를 따로 저장할 수 있습니다.

미리보기 버튼으로 전시관의 모습을 확인하고, HTML 파일을 내려받아 배포용 서버나 웹 호스팅에 게시할 수 있습니다. 저장한 작업은 이 브라우저에서 다시 편집할 수 있습니다.

주의: 이 제작기는 서버 연동 없이 동작하는 정적 페이지입니다. 입력 내용과 작품 이미지는 사용하는 브라우저에만 저장됩니다. 다른 기기에서 공유·공동 편집하려면 JSON 백업 파일을 전달하거나 별도의 서버가 필요합니다. HTML 다운로드가 공개 배포를 의미하지는 않습니다.

이전에 저장한 미술 전시 데이터가 있으면 최초 실행 시 구버전에서 복사하여 표시합니다. 다른 종류의 프로젝트는 기존 저장소에서 제거하지 않고, 새 제작기에서 표시하지 않습니다.
