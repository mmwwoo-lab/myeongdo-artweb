# 명도재 AI 시화 감독 시스템 — 설치 및 운영

## 적용 범위
- 전진식 `jeon-jinsik.html`
- 이성두 `lee-seongdu.html`
- 곽의영 `gwak-uiyeong.html`
- API `api/poem-director.py`
- 브라우저 `ai-poem-director.js`

## 무료 모드 (즉시 사용 가능)
시 선택 → **① 시 분석·구도 설계** → 시어 추출(인물·장소·사물·자연·동물·계절) → 전경·중경·원경 배치 및 정서 파악 → **구도 다시 설계**.
분석은 외부 이미지 모델을 사용하지 않는 규칙 기반 방식입니다. 미술 감독이 결과를 점검해야 합니다.

## 실제 AI 이미지 생성 활성화
관리자가 Vercel 프로젝트 `wolchon-station-people`의 Settings → Environment Variables (Production)에 다음을 직접 설정합니다.

- `OPENAI_API_KEY`: 이미지 API 사용 권한이 있는 OpenAI API 키 (서버에서만 사용, GitHub 금지)
- `MDO_ART_ADMIN_TOKEN`: 20자 이상 무작위 관리자 암호 (서버에서 인증)
- `MDO_IMAGE_MODEL` (선택): 기본 `gpt-image-2.5-flare`, 필요에 따라 지원되는 모델로 변경

키 설정 후 **새 배포**가 필요합니다. 서비스에 비밀키를 직접 입력하거나 브라우저에 저장하지 마세요.
관리자는 문학관의 **관리자 토큰** 입력란에 두 번째 값을 넣고 **② AI 그림 생성 (유료)** 버튼을 누릅니다.
성공 시 후보 이미지가 나타나며, **③ 후보 승인 → ④ 승인 그림 저장** 순서로 다운로드합니다.

## 공개 게시
생성 결과는 브라우저 메모리에서만 유지됩니다. 승인해도 공개 저장소나 Vercel에 자동 게시되지는 않습니다.
다운로드한 JPG를 관리자가 권리 확인 후 `wolchon-station-people/`의 적절한 이미지 폴더에 업로드하고, 작품별 이미지 참조를 갱신하여 배포합니다.
자작시·제공받은 시만 처리하고 원문의 공유 허락을 확인합니다.

## 비용·안전
- 계획 생성은 유료 이미지 API를 호출하지 않습니다.
- 실제 이미지 생성은 **관리자 토큰 검증 이후**에만 호출합니다.
- API 사용 요금이 발생합니다. OpenAI API 대시보드에서 이용 한도를 설정하세요.
- 이미지는 시의 실제 내용에 기반하지만 세부 요소가 누락될 수 있습니다. 게시 전 검수하세요.
- 실존 시인의 초상은 사진 참조 없이 정확한 실물 사진처럼 표현하지 않습니다.
- 제공된 토큰은 웹페이지의 로컬 저장소에 기록하지 않습니다.
- 결과는 이미지 후보이며 자동 출판이 아닙니다.

## 엔드포인트
`POST /api/poem-director`

```json
{"action":"plan","title":"가을 타기","poem":"태울 것이 없으면\n라이터를 켜지 마라","style":"pop","variant":0}
```

`style`: `pop`, `watercolor`, `emotion`, `portrait`.
`action`: `plan` 또는 `generate`.
`generate`는 HTTP 헤더 `X-MDO-ART-ADMIN-TOKEN`이 반드시 필요합니다.

**참고:** 이 시스템은 기존 Python 도형 기반 SVG 시화 기능과 별개입니다. 새 시스템은 서버에 인증 정보를 연결했을 때 생성형 이미지 AI를 사용합니다.
